# 锅盖热点反射天线 · 手机支架（3D 打印）

用一个凹面玻璃锅盖（直径约 31cm，深约 3cm）内贴铝箔当反射面，手机悬在焦点附近，让手机热点往一个方向更强。
本目录是 3D 打印的支架：一个套在锅盖旋钮上的底座，一根方杆，杆端一个托手机的托架。

> 之前的对话记录在 `claude_log.txt`。

## 文件

| 文件 | 作用 | 体积 / 尺寸 | 打印姿态 |
|---|---|---|---|
| `1_base.stl` | 旋钮套筒底座：锥形孔扣在反装的旋钮上，上面是方杆插槽 | 约 37cm³，52×52×57mm | 套筒口朝下，孔内开支撑 |
| `2_rod.stl` | 方杆 12×12×200mm，带刻度槽 | 约 29cm³ | 平放 |
| `6_cradle.stl` | 可滑动、可锁紧的手机托架：一个套在杆上的滑块（方孔 + M3 锁紧螺丝）直接托着底托，上面是后挡板 + 前挡唇 + 两侧挡边，充电线孔从底托贯穿到滑块底部 | 约 42cm³，84×69×32mm | 躺着打印：后挡板贴热床，不用支撑 |
| `3_slider.stl` `4_tray.stl` `5_pin.stl` | 备用方案：滑块 + 可旋转托盘 + 转轴销（手机可沿杆滑动、可转 90°） | — | — |
| `gen_holder.py` | 参数化 STL 生成器，改参数后重新运行即可 | — | — |

目前实际用的组合是 **1_base + 2_rod + 6_cradle**。滑块/托盘/销是没用上的备用方案。

## 生成 STL

```bash
pip install numpy trimesh manifold3d
python3 gen_holder.py
```

## 参数（`gen_holder.py` 顶部）

| 参数 | 当前值 | 说明 |
|---|---|---|
| `knob_d_top` | 40 | 旋钮顶面直径，**已实测**（4cm） |
| `knob_h` | 26 | 旋钮从玻璃到顶面的高度，已实测（约 2.6cm） |
| `knob_d_bottom` | 44 | 旋钮靠玻璃一端的直径，**是按照片估的，还没量**。量完请改这里 |
| `sleeve_wall` | 3 | 套筒壁厚（默认值，不是实测） |
| `knob_gap` | 1.0 | 孔比旋钮每边大 1mm，留给热熔胶，也防止套不进 |
| `bore_extra` | 2.0 | 孔比旋钮深 2mm |
| `phone_w` | 78 | 手机宽 7.5cm + 余量，也是托架槽宽 |
| `phone_t` | 9 | 手机厚度（去壳），**还没量**，托架槽厚 = `phone_t + 2` |
| `rod_len` | 200 | 方杆长度 |
| `use_flange` | False | 底座是否带贴玻璃的大圆盘（关掉更快） |

按当前参数算出的尺寸：套筒孔玻璃端 d=46、顶端 d=42、深 28mm；套筒外径 52mm；方杆底端离玻璃 32mm；杆顶离玻璃 232mm。

方杆上的刻度 = 杆插到底时该刻度离玻璃的距离（mm），每 50mm 一条长线，200mm 处是双线（焦点附近）。

## 组装

1. 底座的锥形孔扣在锅盖凹面的旋钮上，沿套筒下沿和 3 个注胶孔打热熔胶。没有大圆盘，套筒下沿和凹面玻璃之间有约 1mm 的缝，多打点胶填上。
2. 方杆插进底座顶部的方槽，M3 螺丝顶紧（或热熔胶）。
3. 托架的滑块从杆的自由端套上去，杆从滑块的方孔穿过，可以前后滑动。
4. 手机从上面放进托架：背靠挡板，底边压在底托上。充电线的插头从底托中间的孔穿下去，一直穿过滑块，线从滑块底部垂下来。
5. 找到信号最强的位置后，用 M3 螺丝锁紧：螺母压进滑块 +X 侧的六角槽，螺丝从外面拧进去，顶住杆。需要 M3 螺丝和 M3 螺母各 1 个（螺丝 10 到 16mm 长）。

锅盖要朝前或朝上放。朝下的话，手机会从托架里滑出来。

## 打印建议

- 层高 0.28mm（0.4mm 喷嘴）、填充 10%、外壁 2 圈、顶底层各 3 层。
- 杆不要加 brim/raft。
- 底座只在锥形孔内开支撑。
- 之前用 0.2mm 层高，底座要 2 小时、杆要 55 分钟，所以后来把底座去掉了大圆盘、杆从 14×14 改成 12×12，并调整了切片设置。

## 手机的位置

- 球面锅盖焦距约 R/2：31cm 直径、3cm 深，曲率半径约 41.5cm，焦距约 20cm。手机放在离锅盖中心约 20cm 处（17 到 23cm 之间前后微调）。
- 手机的 Wi-Fi 天线通常在顶部或底部边框，不在正中间。手机竖着站在杆的上方，底边离杆的轴线约 16mm；因为充电线孔要穿过滑块，杆孔被挤到了一侧，所以杆比手机中线偏右约 18mm。
- 手机也可以躺着放（顺着杆，两端的天线都落在轴线上），这需要另外做托盘，现有的 `3_slider/4_tray/5_pin` 就是这个方案。
- 读数：托架后挡板背面对着的杆刻度，再加约 10mm，就是手机离玻璃的距离。杆上刻度是杆插到底时离玻璃的距离（mm）。滑块后端能放到的位置约从 70 到 190mm，手机大致在 80 到 200mm 之间可调。
- 锅盖的轴线要对准接收设备，不要斜着。

## 效果

实测下来，信号提升没有比用可乐罐做的天线明显多少。原因主要是手机作为馈源向各个方向都发射，只有一小部分能量打到锅盖上，实际增益大概 3 到 6dB，和可乐罐差不多。

想让效果更明显，从简单到复杂：

1. **固定测试方法**：接收设备放在同一位置，用 WiFi Analyzer 看 dBm，裸手机、可乐罐、锅盖各测一次。
2. 2.4GHz 和 5GHz 各测一次，5GHz 下锅盖相对更大，聚焦会更好。
3. 在手机背面（手机和锅盖之间，靠近手机）加一个小反射板，比如铝箔卡片或半个可乐罐，让手机朝锅盖这一侧发射更多。
4. 沿杆前后各移 2 到 3cm，找信号最强的点。
5. 如果只是想让家里信号更好，把手机放高处、减少遮挡，通常比这个锅盖更有用。
